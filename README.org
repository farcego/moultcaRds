* moultcaRds

** Description

*moultcaRds* is an R package for summarising, analysing and plotting
bird moult card data.

The package is aimed at field moult cards and feather-level moult records.
It provides simple tools to visualise moult extent in wing and tail diagrams.

** Main aims

- Store moult card data in a consistent format than can be easily ported to other related R packages.
- Summarise moult extension by feather tracts and or individual feathers.
- Plot schematic moult extent figures based on Jenni & Winkler book {cite}.
- Prepare moult records for further analysis.
- Keep dependencies minimal (~grid~ es un paquete que se instala junto con R).

** Scripts

**** colSc.R
defines an internal helper that converts normalized moult scores (0–1)
into grey-scale colours for plotting feathers. Darker shades represent
more advanced moult.

**** drawFea.R
Draws an individual feather at a specified position on a moult card.
Feather shape and appearance are controlled by its type, moult status,
and graphical parameters.

**** drawTxt.R
Draws the non-feather elements of a moult card.  Renders labels,
guides, axes, and other graphical components surrounding the feathers.

**** endPlot.R
Restores the graphics state after plotting.  Cleans up the viewport
and graphical parameters initialized by ~initPlot()~.

**** initPlot.R
Initializes the plotting environment for moult card rendering.  Sets
up graphical parameters and viewports restored later by ~endPlot()~.

**** plot.R
Creates a graphical representation of a moult card.  Coordinates the
rendering of feathers, labels, and other card components.

**** wingCard.R
Generates a complete wing moult card.  Uses the supplied moult data to
draw primaries, secondaries, and associated wing labels.
